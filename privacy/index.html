データの取り扱い

プライバシーポリシー

最終更新日：2026年11月9日

取得するもの、使う目的、保存する場所を明らかにします。

1. このサイトとツールについて

「YouTube-Codex Analytics Local」（表示名：Dr.ぽよ チャンネル観測室）は、チャンネル所有者本人が、自分のYouTubeチャンネルを分析し、動画制作に役立てるためのローカルツールです。一般向けの利用登録は受け付けていません。

このサイトはツールの説明用です。サイト上にログイン、入力フォーム、独自のアクセス解析、YouTube APIへの接続機能はありません。独自のCookieによる追跡も行いません。

2. 取得するデータと権限

ローカルツールはYouTube API Servicesを利用し、本人の許可を受けて、次の取得可能な情報を読み取ります。

  • チャンネルと公開動画のタイトル、公開日時、動画の長さなどの情報、公開統計。
  • 視聴回数、視聴時間、平均視聴時間、平均再生率、視聴者維持率、流入元などの集計値。
  • インプレッション、クリック率、登録者の増減など、権限内で提供される集計値。

要求する権限は youtube.readonly と yt-analytics.readonly の2つです。収益データの権限、動画の投稿・編集・削除を行う権限は要求しません。個々の視聴者を識別するための情報も取得しません。

Googleによる取り扱いについては、Googleプライバシーポリシーをご確認ください。

3. 利用する目的

取得データは、本人のチャンネルの状況を把握し、企画、台本、タイトル、サムネイル、映像構成を改善するために使います。取得日時、対象期間、実測値と推測を区別して記録します。

APIのデータが空の場合や、反映されていない場合は、未取得として扱います。未取得の値を0に置き換えたり、比較条件が異なる動画の数値だけで成果を断定したりしません。

4. 外部サービスへの送信

本人がCodexで分析するとき、必要な集計データや関連する制作資料をOpenAIへ送信して、分析や改善案の作成を補助させる場合があります。OpenAI側での保存やモデル改善への利用は、適用される規約・プライバシーポリシーと利用者のアカウント設定に従います。本サイトは、その保存期間や学習利用の有無を一律には保証しません。

詳しくは、OpenAIのプライバシーポリシーをご確認ください。

このサイトの公開先にGitHub Pagesを使う場合、GitHubはセキュリティの目的で訪問者のIPアドレスを記録・保存します。詳しくは、GitHubのプライバシーに関する声明およびGitHub Pagesのデータ収集の説明をご確認ください。

5. 保存・更新・削除

分析記録は、本人のPCに、取得日時別のJSONやMarkdownとして保存します。認証情報はWindows資格情報ストアで管理し、分析記録やサイトの公開ファイルに含めません。OpenAIへ送信した内容には、前項の取り扱いが別途適用されます。

保存記録は本人が管理します。自動削除機能は現在ありません。YouTube APIの規定に従い、認証済みの統計・分析情報を保存する間は30日ごとに認可の継続と対象動画の存在を確認し、その他の保存メタデータは原則30日以内に更新または削除します。

保存データの削除を本人が指示した場合は、可能な限り速やかに、7日以内に対応します。連携の認可を取り消した場合は、YouTube APIの規定に従って保存データを整理し、30日以内に削除します。削除対象はPC上の記録・資格情報、OpenAI製品上の保存内容など、保存先ごとに確認します。

規定の詳細は、YouTube API ServicesのDeveloper Policiesをご確認ください。

6. 連携を取り消す方法

Googleアカウントのサードパーティ接続管理から、このツールへのアクセス許可を取り消せます。

連携の取り消しと、保存済みの記録の削除は別の操作です。取り消した時点でPCやOpenAIへ保存した内容が自動削除される仕組みはありません。保存先ごとに削除を行います。本ツールの記録を削除しても、YouTube上の動画や統計は削除されません。

7. お問い合わせと変更

本人向けツールの利用やデータの取り扱いに関する連絡先は、GoogleのOAuth同意画面に表示されるサポート連絡先をご確認ください。

データの取得範囲、利用目的、保存・共有方法を変更する場合は、この説明と更新日を見直し、必要に応じて利用者の同意を得ます。
