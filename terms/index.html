利用条件

最終更新日：2026年11月9日

観測した事実を確かめ、制作への判断は本人が行います。

1. 利用対象と目的

「YouTube-Codex Analytics Local」（表示名：Dr.ぽよ チャンネル観測室）は、チャンネル所有者本人が、自分のYouTubeチャンネルを分析し、動画制作を改善するためのツールです。現在、第三者向けのサービス提供や一般向けの利用登録は行っていません。

このサイトは、ツールの目的とデータの取り扱いを説明する案内ページです。分析ツールの実行や、YouTubeへのログインは、このサイト上では行いません。

2. YouTube API Servicesの利用

本ツールはYouTube API Servicesを利用します。本ツールを利用する際は、この利用条件とプライバシーポリシーに加え、YouTubeの利用規約にも従うことに同意するものとします。

本人が管理するチャンネルについて、本人の許可の範囲で読み取りを行います。動画の投稿・編集・削除を行う権限は要求しません。

3. データと分析の限界

データは取得日時点の情報です。集計の遅れ、後日の修正、非表示の指標などがあり、YouTube Studioの表示と異なる場合があります。集計対象の期間と時間帯を確認したうえで扱います。

未取得の値は未取得として扱い、推測や改善案は観測された事実と区別します。Codexによる分析や提案にも誤りが含まれる可能性があるため、制作への採用は本人が元データと内容を確認して判断します。再生回数の増加などの成果を保証するものではありません。

4. 制作と公開の判断

分析結果は、次の企画、台本、タイトル、サムネイル、映像構成を検討するための材料として使います。承認済みの台本の変更や、動画・サムネイル・動画情報の公開変更は、それぞれ本人が認めた範囲で行います。

5. 提供主体と変更

本ツールはチャンネル所有者による個人運用の制作支援ツールで、Google、YouTube、OpenAIの公式製品ではありません。

機能やデータの取り扱いを変更する場合は、この案内と更新日を見直します。利用やデータの取り扱いについては、GoogleのOAuth同意画面に表示されるサポート連絡先をご確認ください。
